# Contract: Design System Artifacts Structure

**Feature**: `006-design-system-guidelines`

## Required Files & Document Sections

### 1. `docs/design_system/README.md`
- Design philosophy (Modern, Flat, High-contrast, Mobile-first, Thumb-friendly)
- Target platforms (Android, iOS)
- Directory layout & documentation guide

### 2. `docs/design_system/tokens.md`
- Color System (Core, Semantic, Light & Dark themes, 10-color Category palette)
- Typography Scale (Display numbers, Titles, Body, Captions)
- Spacing & Grid (8dp baseline)
- Corner Radii (8dp, 12dp, 16dp, 20dp)
- Shadows & Elevation (Flat style with `elevation: 0` and translucent borders)

### 3. `docs/design_system/components.md`
- Screen Structure & AppBars
- Overview / Hero Summary Cards
- List Item Cards
- Horizontal Filter Chips
- Currency Form Inputs & Formatters
- Action Buttons & Dialogs
- BottomSheet Modals
- Empty States
- Banner Ad placement

### 4. `docs/design_system/screen_audit.md`
- Screen-by-Screen alignment review matrix for all 9 screens in the app
- Discrepancy checklist & harmonization steps

### 5. `docs/design_system/recipes.md`
- Standard CRUD Screen Template
- Standard BottomSheet Form Template
- Standard Detail / Transaction Timeline Template
