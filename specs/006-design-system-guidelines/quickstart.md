# Quickstart & Validation Guide: Design System

**Feature**: `006-design-system-guidelines`

## Validation Checklist

1. **Tokens Completeness**:
   - Verify `docs/design_system/tokens.md` contains exact hex codes, typography sizing, radii, and dark/light mode pairs.
2. **Component Library Completeness**:
   - Verify `docs/design_system/components.md` details AppBar, Card, Filter Chip, Input Formatter, Button, BottomSheet, and Empty State patterns.
3. **Screen Audit Completeness**:
   - Verify `docs/design_system/screen_audit.md` covers all existing screens (Dashboard, Transactions, Loans, Budgets, Recurring, Statistics, Saving Goals, Export/Backup, Settings).
4. **Code Recipes Validation**:
   - Verify `docs/design_system/recipes.md` provides clean, compilable Flutter code snippets for building new screens.
